# BGT208 – Yapay Zekâ ve Siber Güvenlik

Bu repository, **BGT208 Yapay Zekâ ve Siber Güvenlik** dersi kapsamında kullanılan ders materyallerini, Python/Google Colab uygulamalarını ve proje çalışmalarını içermektedir.

## Dersin Amacı

Bu dersin amacı; öğrencilerin yapay zekâ, makine öğrenmesi ve derin öğrenme ile ilgili temel kavramları öğrenmeleri ve makine öğrenmesi yöntemlerinin siber güvenlik problemlerinde nasıl kullanılabileceğini uygulamalı olarak kavramalarıdır.

Ders kapsamında teorik konular, Python tabanlı uygulamalar ve siber güvenlik veri setleri üzerinde gerçekleştirilen çalışmalar birlikte yürütülecektir.

## Dersin İşlenişi

Ders haftada **2 saat** olarak yürütülmektedir.

- **1–7. haftalar:** Konu anlatımı ve uygulamalar
- **8. hafta:** Ara sınav
- **9–14. haftalar:** Proje geliştirme ve uygulama

Uygulamalarda ağırlıklı olarak **Python, Google Colab, GitHub ve makine öğrenmesi kütüphaneleri** kullanılacaktır.

## Proje

Ara sınav sonrasında öğrenciler, yapay zekâ ve makine öğrenmesi yöntemlerini kullanarak bir **siber güvenlik problemi** üzerinde proje geliştirecektir.

Projeler aşamalı olarak yürütülecek ve GitHub üzerinden takip edilecektir.

Temel proje süreci:

**Problem Belirleme → Veri Analizi → Veri Ön İşleme → Model Geliştirme → Model Değerlendirme → Güvenlik Değerlendirmesi → Sunum**
